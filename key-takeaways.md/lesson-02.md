# Version Control System

Hệ thống quản lý phiên bản

- Có các kiểu lưu VCS
  -> Local: máy cá nhân
  -> Centralize: máy chủ tập trung
  -> Distributed: nhiều máy khác nhau

# Các câu lệnh git

git init
git add <file_name>
git add .
git commit -m "message"

# Các vùng work của git

- local: vùng của máy cá nhân
- working directory: vùng sau khi đã khởi tạo git
- staging area: vùng sau khi add các file thay đổi từ working, tạo version commit
- repository: vùng chứa các file thay đổi từ staging sau khi commit
